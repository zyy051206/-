# 个人作品集

这是一个只用 HTML、CSS 和少量 JavaScript 编写的本地作品集首页，适配电脑和手机，不需要安装依赖或连接网络。

## 预览

在本地打开 `index.html` 即可预览。也可以在此文件夹运行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8000`。项目卡片使用了同一工作区中真实项目的截图；其项目链接依赖原工作区的相对目录结构。

姓名与邮箱暂未展示。添加真实联系方式后，可在页面 `#contact` 区块更新。

## 实验报告目录

首页导航和“实验报告”区块均可进入 `reports/index.html`。目录收录 11 份实验记录，支持关键词搜索和主题筛选：

- 六个饼图专题：基础饼图、标签优化、尺寸、绘制空间、环形图和嵌套环形图。
- 条形图与折线散点图实验。
- 归并插入混合排序、四种排序算法比较和 UserCF 推荐实验。

详情页提供实验目的、实现要点以及已有数据、运行截图、配置代码和报告附件。UserCF 原版和优化版合并在同一条目中保留下载。报告目录的依赖和附件保存在 `reports/` 内，离线打开也能运行；原首页的其他项目仍沿用工作区相对链接。

检查已覆盖目录搜索、分类筛选、代码复制、附件路径、13 个图表演示页面和手机宽度下的页面排版。本次更新为本地网站更新。
